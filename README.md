# 业务数据看板

基于 ECharts + Tailwind CSS 的汽车销售运营数据看板单页应用。

## 功能模块

- **KPI 概览**：总线索、到店量、成交订单、交车量、总积分、转化率
- **线索入口漏斗**：线索 → 有效 → 意向 → 邀约
- **到店接待流程**：到店 → 试驾 → 回访 → 成交
- **结果指标**：订单 / 交车
- **积分看板**：排行榜、来源占比、多维切换
- **多维下钻分析**：全国 → 大区 → 小区 → 门店 → 顾问（支持点击下钻）
- **趋势分析**：日 / 周 / 月切换
- **产品体验**：外观/内饰/动力/空间/智能/服务 雷达对比
- **线索渠道分布**：来源渠道饼图
- **明细数据表**：门店 / 顾问维度

## 技术栈

- HTML5
- Tailwind CSS（CDN）
- ECharts 5.4（CDN）
- 原生 JavaScript（无构建依赖）

## 本地运行

```bash
# 方式一：直接打开
open index.html

# 方式二：使用 HTTP 服务器
python -m http.server 8080
# 然后访问 http://localhost:8080
```
