# 业务数据看板

汽车销售运营数据看板，存放所有历史版本与最新版本。

## 版本说明

| 版本 | 路径 | 状态 | 说明 |
|---|---|---|---|
| **v1（第一版）** | `legacy/v1/index.html` | 已归档 | 完整模块版：KPI卡、线索漏斗、到店流程、积分看板、多维下钻、排行榜、产品体验雷达、趋势分析、明细表。最初基于白板草图设计。 |
| **v2（当前最新版）** | `index.html` | ✅ 使用中 | 首页三大模块版：按"线索入口 / 到店接待 / 结果面板"分页布局，每张指标卡片更大；顶部加日期范围筛选器，区间合计动态计算，含总览条、转化率、环比、同比。 |

## 目录结构

```
dashboard/
├── README.md               ← 本文件
├── index.html              ← v2 当前最新版
├── .gitignore
└── legacy/
    └── v1/
        ├── README.md       ← 第一版说明
        └── index.html      ← 第一版完整代码
```

## 在线预览

- 最新版（v2）：直接打开 `index.html`
- 历史版（v1）：打开 `legacy/v1/index.html`

## 版本历史

- **v2**：重构首页结构，按线索入口/到店接待/结果面板三大模块分页，添加日期范围筛选与动态汇总。
- **v1**：首版，基于白板草图的多模块布局（漏斗/积分/下钻/排行榜/雷达）。

## 技术栈

- 单文件 HTML（无需构建）
- Tailwind CSS（CDN）
- ECharts 5.4（CDN）

## 本地运行

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```
