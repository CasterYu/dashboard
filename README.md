## 📖 项目说明

汽车销售运营场景下的数据看板，单文件 HTML 部署，零构建、零依赖。

- **v3.6（当前）**：底部「经营结果趋势分析」改为**指标多选折线图**：默认显示「意向线索 / 到店 / 锁单」3 条曲线，可在 10 项指标中任选最多 4 项；绝对量指标（线索、到店、锁单等）使用左侧 Y 轴，阶段转化率（意向线索→到店、到店→试驾、试驾→锁单）使用右侧百分比 Y 轴；**当所选绝对量指标峰值相差 10 倍以上时自动切换为「归一化对比」（各指标按自身峰值缩放为 100%），也可手动切换；悬停时统一展示缩放百分比与真实值**。三大板块展开折线图保留原有交互。
- **v3.4（历史）**：三大板块支持「展开时间轴」：展开后卡片墙替换为按日多指标折线图（默认全选、可增减、至少保留 1 项、可全选恢复，多板块互不影响）；收起态移除卡片右下角迷你走势。
- **v3.3（历史）**：把右侧全链路七阶段转化漏斗放大，改为更醒目的横向渐变条，每阶段名称与数值置于条内，右侧以独立徽章展示「环比上一阶段转化率」，整体转化率/最大流失/线索→交付等摘要保留在漏斗底部。
- **v3.2（历史）**：顶部新增六级组织树筛选（全国 → 大区 → 小区 → 门店 → 岗位 → 人员），默认单选、可切 PK 模式做同级横向对比；补回全链路七阶段转化漏斗；岗位支持「一岗一人 / 一岗多人」，空缺岗位在筛选器内置灰标注「本店暂无」、在对比中显示 `—` 且不参与排名。
- **v3.0 / v3.1（历史）**：左右分栏布局、积分看板、趋势分析、多维下钻、明细数据表等模块。
- **v1（已归档）**：基于原始白板草图的「大而全」实现。

### 🧭 组织树与岗位编制

```
全国 → 大区 → 小区 → 门店 → 岗位 → 人员
```

| 岗位 | 编制规则 |
|:---|:---|
| 店长 | 一岗一人（每店 1 人） |
| 销售顾问 | 一岗多人（每店 2 ~ 4 人） |
| 线上直播 | 一岗多人，部分门店空缺 |

### 🔀 两种筛选模式

- **单选模式（默认）**：五级级联下拉逐级下钻，数据为该节点的区间汇总；未选门店时岗位与人员下拉置灰。
- **PK 模式**：在同一层级勾选 2 ~ 6 个对象做横向比较（例如门店比较）。

### 📈 板块展开时间轴口径

- 时间粒度：**跟随顶部日期范围按日**（7 / 30 / 90 天均按日，点数过多时自动稀疏采样，不影响合计口径）
- 指标勾选：默认全选该板块全部指标；可任意增减，**至少保留 1 项**（最后一项不可取消）
- 数据来源：按当前组织范围逐层汇总后的叶子日序列，与上方 KPI 卡片**同源同口径**
- 比率类指标若被纳入，按 `sum(分子) / sum(分母)` 逐日重算，不做百分比平均

### 📊 经营结果趋势分析口径

- 可选指标：新增线索、试驾、交付、邀约排程、意向线索、意向线索→到店 转化率、到店→试驾 转化率、试驾→锁单 转化率
- 默认选中：意向线索、到店、锁单
- 多选限制：最少 1 项，最多 4 项；选中第 5 项时自动替换最早选中的指标
- 阶段转化率按当前组织范围与所选时间粒度，以 `sum(下游指标) / sum(上游指标)` 重算，不直接平均日转化率
- 绝对量走左侧「数量」Y 轴，转化率走右侧「转化率」Y 轴（0–100%）；只选某一类时隐藏另一类空轴
- **量级悬殊自动归一化**：当选中的多个绝对量指标峰值相差 ≥10 倍时，自动切换为「归一化对比」模式，所有绝对量按各自峰值缩放为 0–100%，统一走单个百分比 Y 轴；阶段转化率仍以真实百分比显示在同一轴上。用户可点击胶囊区的「绝对量对比 / 归一化对比」手动切换。悬停 tooltip 同时显示缩放百分比与真实值

### 📐 PK 对比口径约定

- **不做任何累加**，只做并列对比；总览区不出现合计值
- 总量指标直接对比；比率指标按「分子 / 分母」分别累加后重算，**绝不把百分比平均或相加**
- 每行自动标出最优（绿）/ 最差（红），并显示与基准对象的差值、差值百分比（点击表头可切换基准）
- 空缺岗位显示 `—`，**不与 0 混淆**，且不参与该行的最优/最差着色与排名
- 环比为各对象**各自**对比上一等长周期，保证横向公平
- 组织范围过小导致深层指标为 0 时，漏斗底部会给出样本偏小的提示

## 🔄 更新与推送

修改代码后，提交并推送到 GitHub：

```powershell
cd "D:\projects\dashboard"
git add .
git commit -m "feat: 你的变更说明"
git push origin main
```

需要推送所有 tag：

```powershell
git push origin --tags
```

首次推送请使用 `push-to-github.ps1` 脚本（脚本内填入 GitHub 用户名与 PAT）。

> ⚠️ PAT 请勿提交到仓库，用完即吊销重发。
