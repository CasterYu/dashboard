# 接口清单 · 业务数据看板 v5.12

> 后端入口 `server/index.js`，路由挂载前缀 `/api`。base = http://127.0.0.1:3777

## 0. 健康检查
| 接口 | 说明 |
|---|---|
| GET `/api/health` | 返回 { ok, version, authMode } |

## 1. 鉴权 auth.js
| 接口 | 入参 | 说明 |
|---|---|---|
| POST `/api/auth/login` | { empNo, password } | 登录，返回 token；有 IP 限速 |
| GET `/api/auth/me` | header Authorization | 当前用户信息 |
| POST `/api/auth/change-password` | { oldPwd, newPwd } | 改密（需登录） |
| POST `/api/auth/logout` | — | 登出 |

## 2. 组织 org.js
| 接口 | 说明 |
|---|---|
| GET `/api/org` | 全量组织树（六级），含 posts 岗位定义 |

## 3. 指标 metrics.js（聚合查询，按任职区间时间切片）
| 接口 | 入参 | 说明 |
|---|---|---|
| GET `/api/metrics` | node, from, to, inclInactive | 节点区间指标合计 + 积分（积分按当时岗位权重现算） |
| GET `/api/persons` | node, from, to, inclInactive | 人员级汇总（散点/积分榜/明细数据源） |
| GET `/api/nodesums` | nodes[], from, to | 批量节点区间合计（下钻热区/榜单） |

## 关键口径备注
- **积分**：不落库，`metricsService.pointsExpr` 按「当时岗位」权重 `pw_*` 现算（=Σ 指标×权重）
- **node 参数三态**：0=全网；正整数=单根子树；{includeIds,excludeIds}=显式多根（并集减排除）
- **任职区间**：归属按「当时架构」（dm.date 落在 node_paths 区间内），防调岗后重复计数
