# 数据字典 · 业务数据看板 v5.12

> 本文件沉淀数据库 13 张表的结构、字段含义与数据来源，供改后端时快速查证，避免每次重读代码。

## 数据库概况

- 路径：`server/data/dashboard.db`（SQLite，WAL 模式，`PRAGMA foreign_keys = ON`）
- 建表位置：`server/db.js`（10 张主表）+ `server/services/actionScoring_v4.6.js`（3 张评分表）
- 数据来源三类：**真实**（Excel 导入）/ **演示**（seed.js 虚拟区）/ **规则配置**（出厂 seed）

---

## 1. org_nodes —— 六级组织树

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增主键 |
| name | TEXT | 节点名 |
| level | TEXT | 全国/大区/小区/门店/岗位/人员 |
| parent_id | INTEGER | 父节点（REFERENCES org_nodes.id，无级联，删父前须先删子） |
| post_key | TEXT | 岗位/人员节点所属岗位 key |
| store_id | INTEGER | 岗位/人员节点所属门店（冗余，加速汇总） |
| status | INTEGER | 1=在职 0=停用（软删除） |
| deactivated_at | TEXT | 停用时间 |
| emp_no | TEXT | 人员工号（唯一索引，仅 level='人员'） |

- 唯一索引：`idx_org_empno`（emp_no 非空 且 level='人员'）
- 全国根节点 id = 382；虚拟区（演示数据）根 id = 2936

## 2. posts —— 10 岗位编制与积分权重

| 字段 | 说明 |
|---|---|
| key | 主键（productExpert/deliveryManager/...） |
| name / color | 岗位名 / 配色 |
| min_cnt / max_cnt | 编制区间 |
| pw_locked ~ pw_opportunities | 6 项积分权重（积分=Σ 指标×权重，查询时现算） |

## 3. daily_metrics —— 人员×日期×11 项指标

- 主键 `(person_id, date)`
- 列：leads/valid_leads/intent_leads/invites/arrivals/test_drives/test_reviews/return_visits/opportunities/locked/delivered（下划线存储）
- **积分 points 不落库**，查询时按岗位权重 `pw_*` 现算（metricsService.pointsExpr）
- 数据来源：seed.js 演示（虚拟区 228 人 × 365 天 = 83220 行）+ importMetrics 真实导入（非虚拟区）

## 4. action_scores —— 动作评分明细（积分模块主表）

| 字段 | 说明 |
|---|---|
| person_id / emp_no / person_name | 人员（工号为空即虚拟人物，新规则已拒绝） |
| post_key / store_id / store_code / store_name | 岗位/门店 |
| date / item / action / score | 日期/拿分项/动作/得分 |
| ok | score>=0 ? 1 : 0 |
| evidence / order_no | 证据 / 订单号 |

- 唯一：`(person_id, date, item, action, order_no)`

## 5. action_daily_sums —— 个人×拿分项日汇总

- 主键 `(person_id, date, item)`
- 字段：target/cnt/target_score/score（目标/次数/目标分/得分）

## 6. node_paths —— 人员→祖先物化路径（带任职区间）

- 主键 `(person_id, ancestor_id, from_date)`
- 每段携带当时 store_id/post_key；区间互不重叠，聚合不重复计数

## 7. person_assignments —— 任职记录（真源）

- 主键 `(person_id, from_date)`
- 调岗 = 关旧段（to_date=前一日）+ 开新段（to_date=哨兵 9999-12-31）

## 8. import_logs —— 导入批次留痕

- type：org / metrics / scoring / rules / demo-org
- rows_ok / rows_failed / report_json（回滚凭据）

## 9. users —— 登录账号

- emp_no 唯一，与人员节点 1:1
- role：hq/regional_lead/area_lead/store_lead/employee

## 10. roles —— 角色权限

- code 主键；scope_level（大区/小区/门店/人员，NULL=全树）
- permissions JSON 权限点

## 11. user_scope_nodes —— 显式授权

- (user_id, node_id) 唯一；mode include/exclude；双外键 ON DELETE CASCADE

## 12. meta —— 元信息（schema_version 等）

## 13. action_rules —— 动作积分规则（拿分项规则）

- 主键 `(post_key, item)`；per/cap_normal/must_do/judge 等
